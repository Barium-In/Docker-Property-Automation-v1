# The modules the Asterisk 22.12 image builds (Dockerfile.ast22), one per line.
# This list is the only place they are named:
# - the build enables exactly these in menuselect, and fails if a .so is missing
#   or one not listed here appears;
# - tests/check-ast22.sh checks that each one is loaded and running.
# Every module a listed one depends on is listed too.
# Core features need no entry: Answer, Wait, Ringing, Hangup, Goto, GotoIf, Set,
# local channels, the web server and the DNS manager are built into the binary.
# Left out on purpose: func_env, func_shell and app_system (file and shell access
# from the dialplan or ARI), CDR and CEL backends, other channel drivers, SIP
# MESSAGE, MWI, presence, T.38 and the anonymous endpoint.
